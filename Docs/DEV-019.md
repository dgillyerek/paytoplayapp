# DEV-019 — Play layout (board safe rect + HUD dock)

Status: **wired in Play Mode** (`Board.unity`) per DES-003 mock + `Docs/Design/des-003-004-handoff.md`.

Portrait reference: **1080×1920**. Design Y% is from the **top**; Unity / `PlayLayout` use Y = 0 at the **bottom**.

## Acceptance

- Order tray rendered **only** inside the bottom dock (Design Y 70–100%). **Zero** overlap with cell rects. Dock plate is the thin `UI_OrderDock_Panel` inventory strip — never stretched to the full 30% band (that was covering the board). A `RectMask2D` on the dock clips any card overflow.
- Board hero in Design Y **~10–66%**. 7×5 is inset (`BoardSafeRect`) so the Garden Crate sits left/center on the board without covering cells.
- Top Design Y **0–8%**: energy + coins left. Maya top-right HUD band only (not on the board). Small Goal pill **under** that row, centered: “Restore the Front Garden”.
- Chrome stack matches `DES003_PlayHud_LayoutMock`: energy L + Maya R → Goal pill → board → 3-card dock.
- **≥16dp** gap between the 7×5 edge and any permanent HUD chrome (vertical or horizontal).
- Visual-only **5 inventory slots** in the dock via Design `UI_OrderDock_Panel` (DEV-007 inventory is paused — no inventory sim). Compact order cards: icon + title; the active card is the deliver hit target (no stacked DELIVER button).
- Visual parity with splash (Design art; stubs `UI_OrderDock_Panel`, `UI_GoalPill`). Production crate is `ENV_FG_GardenCrate_Idle`. No debug toast, no bootstrap diagnostic overlay, no world-space letter tokens.
