## What to capture

≤8 second phone recording (or Editor Game-view at phone aspect) showing **one continuous hero loop**:

1. **Crate** — tap Garden Crate; spit piece with soft squash + arc; charges pip updates  
2. **Merge** — drag two matches; pop + soft gold sparkle; result lands readable  
3. **Deliver** — tap DELIVER on ready order; card settles; reward flies toward Maya / wallets  

Optional: one soft haptic note on merge (device).

## PASS

- Feels premium next to Travel Town / Merge Mansion class juice (not Unity default lerp)
- Timing in Style Bible §5 windows
- No debug overlays, no cream plates, no clipped type in the clip
- Same build tip as the phone still used for mock comparison

## FAIL

- Flat fade / instant swap with no squash-pop
- Juice missing on any of the three beats
- Clip shows prototype chrome
- Still-only submission (no clip) → **not done**
