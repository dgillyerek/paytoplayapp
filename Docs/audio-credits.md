# Audio credits: runner / battle attack, hit and death sounds (Theme A)

Added 2026-11-20 (branch `audio/runner-attack-sfx`). Reworked the same day so every layer fits a medieval
fantasy kingdom (Derek: the first pass sounded too futuristic / not period-correct). **Every file is CC0 1.0
(public domain) or original acoustic-sounding synthesis; nothing needs attribution and nothing is
non-commercial-only.** Commercial use is allowed. Credit below is a courtesy.

Rebuild: unpack the packs below into one folder (`x_medieval/`, `kenney_impact-sounds/`, `kenney_rpg-audio/`,
`x_80-CC0-creature-SFX_0/`, `x_80-CC0-creature-sfx-2/`, `x_80-CC0-RPG-SFX_0/`, `x_sfx_breaking_and_falling/`,
`x_100-CC0-wood-metal-SFX/`, `x_sword_clash_-_starninjas_0/`, `x_sword_-_starninjas_1/`, `x_weapons-apparel/`,
`x_wings_flap_large/`, `x_ice_shatters/`, `x_wind/`, plus `fire-1.wav`, `rain-thunder.ogg`, `short wind sound.wav`),
then `AUDIO_SRC=<folder> python3 scripts/audio/medieval_runner/build_attack_sfx.py <out>` and copy `<out>/*.ogg`
into `Assets/ThemePack/fantasy_kingdom_a/audio/`. Output: mono, 44.1 kHz, Ogg Vorbis q4, true peak <= -3.5 dBFS,
active RMS about -18 dBFS (hurt layers -19).

There are no synthesized electronic, sci-fi, laser, zap, beep, or rising-whine layers. Magic is organic:
recorded chapel bells, fire, wind, ice, a low choir swell, and earth rumble.

## Mix

Each cue picks a random variant per play, never the same one twice in a row (`AudioVoiceLimiter.NextVariant`), with
+/-4-6 % pitch and up to 12-15 % volume randomization (`pitch_jitter`, `volume_jitter` in `audio.json`). Voice caps and
retrigger gaps (`max_voices`, `min_gap`) stop a volley stacking. Cue volumes sit at 0.38-0.62 against music at 0.55
(combat about 6 LU above the music).
