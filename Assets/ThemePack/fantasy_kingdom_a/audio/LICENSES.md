# Theme A (fantasy_kingdom_a) audio: sources and licenses

Every sound in this folder is **original, procedurally synthesized audio** made for this project by
`scripts/audio/gen_theme_a_audio.py` (numpy + scipy oscillators, filtered noise and envelopes, fixed seed 20261026,
encoded to Ogg Vorbis with ffmpeg/libvorbis). **No third-party samples, recordings, loops or sound libraries were used.**

- **License:** CC0 1.0 Universal (public domain dedication), https://creativecommons.org/publicdomain/zero/1.0/
- **Commercial use:** allowed, no attribution required.
- **Author:** generated by Grok Bot for Derek Gilbert, 2026-10-26.
- **Regenerate:** `python3 scripts/audio/gen_theme_a_audio.py` (writes here; output is deterministic).

Rules for adding sounds to this pack: only CC0 / public-domain or procedurally generated files. Add a row below with
the file's source URL and license for anything that is not generated by the script above. Cue ids and which game
events play them live in `audio.json` (white-label: another theme pack ships its own `audio.json` and files).
