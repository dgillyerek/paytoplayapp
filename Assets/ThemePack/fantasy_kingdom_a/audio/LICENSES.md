# Theme A (fantasy_kingdom_a) audio: sources and licenses

This pack mixes two kinds of files. **Every file is CC0 1.0 / public domain; none needs attribution and none is
non-commercial-only.**

1. **CC0 recordings (everything except the procedural files below):** village, UI, economy, battle, runner, boss and music files
   built from real recordings published as CC0 by Kenney (kenney.nl) and creators on OpenGameArt.org. Each row below names the pack,
   its page URL and the source clips. The license field on each page was checked to be CC0 on 2026-10-27.
   Rebuild: download the packs into a folder, then `AUDIO_SRC=<folder> python3 scripts/audio/medieval_runner/build.py`
   and `.../build_music.py`, `.../build_hub.py`, `.../build_loops.py` (trim, layer, high-pass, loudness-normalize, Ogg Vorbis via ffmpeg/libvorbis).
2. **Procedural (original):** `sfx_powerup.ogg` and `sfx_pickup_pop.ogg`, synthesized by
   `scripts/audio/gen_theme_a_audio.py` (numpy + scipy, fixed seed 20261026).
3. **Layered attack / hit / death sets (2026-11-20, medieval rework the same day):** every `sfx_atk_*`, `sfx_imp_*`,
   `sfx_hurt_*` and `sfx_die_*` file, built by `scripts/audio/medieval_runner/build_attack_sfx.py` (fixed seeds) from the
   CC0 recordings named in each row plus original acoustic-sounding synthesis (swept-noise whooshes, ringing metal or
   bowstring partials, low choir formants, body thumps, ember crackle, earth rumble, a synthesized stone-hall
   convolution tail). No electronic, sci-fi, laser, zap, beep, or rising-whine layers. They replace the single-file
   `sfx_lyra_shot`, `sfx_rowan_shot`, `sfx_oakenshield_throw`, `sfx_enemy_hit`, `sfx_enemy_death`, `sfx_magic_impact`,
   `sfx_sword_hit` and `sfx_arrow_hit` (removed). Full credit list: `Docs/audio-credits.md`.

- **License:** CC0 1.0 Universal (public domain dedication), https://creativecommons.org/publicdomain/zero/1.0/
- **Commercial use:** allowed, no attribution required (credit to the creators below is appreciated, not required).
- **Assembled by:** Grok Bot for Derek Gilbert, 2026-10-26 (procedural), 2026-10-27 (recordings), 2026-11-16 (Lyra magic shot), 2026-11-20 (runner attack sets, medieval rework).
