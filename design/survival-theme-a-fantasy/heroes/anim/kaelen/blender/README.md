# Kaelen Blender file

One file: `KAELEN.blend` (Blender 4.2.3). It holds the rig, body, props, cape rig and cape and every animation clip as an Action (fake user + muted NLA track). No action assigned = rest pose.

Actions (30 fps): idle (1-299), walk (1-36), attack_dualslash (1-110).

Built from the game-ready exports in ../final/ (unchanged). Cape spring sim is not baked. Full object list, sources and import settings: `README_KAELEN_blend.md`.

Unity cape collider specs: ../final/CAPE_ATTACH.md.
